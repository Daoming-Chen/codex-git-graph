## 当前界面与历史读取

HTTP 和 MCP 共用一套面板界面。历史行高为 24px，轨道间距为 20px；普通提交使用实心圆点，合并提交使用空心圆，WIP 使用虚线环。作者显示在作者列与详情中，节点不显示作者缩写。行底色按轨道颜色向右渐隐，悬停和选中时有额外样式。实现见 `src/ui/app.js` 的图形常量、节点渲染，以及 `src/ui/style.css` 后部的覆盖规则；第二版规格中的 28px 已被替换。

初次打开默认保留历史区域，不自动展开详情。导航默认收起，详情默认停靠底部；可切换右侧停靠，宽度达到 1100px 时使用宽屏布局。布局偏好可覆盖默认选择，窄屏按响应式规则展示。

历史默认读取 300 条，每次续载增加 300 条；单次查询最多 2000 条，通过 `offset` 分页继续读取。累计加载量不再受 2000 条上限限制，可手动续载或开启滚动续载。界面渲染所有已加载的行，尚未使用虚拟列表；大范围加载会增加查询和渲染开销。查找仅覆盖已加载记录。

历史筛选在 Git 查询层执行，支持多引用、分支通配符、第一父提交、reflog 及远程／标签／Stash 引用显隐。引用和 HEAD 跳转会解析实际提交；两端点比较表示 A 树到 B 树的差异，合并提交详情可选择父编号。历史提交还可与操作工作区比较。

## Git 操作与审阅

`src/actions.mjs` 汇总基础动作，远程引用和历史／工作区动作分别由 `src/remote-actions.mjs`、`src/history-actions.mjs` 校验。所有 Git 写操作仍经过 prepare/execute；删除、丢弃及需要确认的历史重写会在准备阶段校验确认信息。详细范围和安全限制见 [README](../README.md#读写边界)，功能扩展记录见[功能对齐报告](review/10-git-graph-parity.md)。

`src/review.mjs` 提供结构化文件清单、逐文件 diff、修改前／后／当前内容、签名和包含关系；`src/ui/features.js` 提供操作表单、扩展筛选、审阅进度和仓库配置入口。文件内容查看在面板内完成，冲突内容仍需在外部编辑器修改。

仓库配置和审阅进度通过独立的偏好接口保存，不属于 Git prepare/execute 动作。配置与审阅进度保存在 Git common dir，布局偏好保存在浏览器，具体规则见[数据保存](install-lifecycle.md#数据保存)。
