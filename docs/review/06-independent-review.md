## 检查与修正

代码复核推动修正了跨 Worktree 的公共 Git 目录写队列、prepare 与已审阅版本绑定、排队后过期复查、流式内容指纹、有界未跟踪预览、作者身份指纹和错误输出脱敏。身份时间戳排除在指纹外，避免静止工作区被误判为变化。协调和去重仅覆盖同一服务进程，不是跨进程事务。

浏览器独立操作确认：引用范围实际缩小可达历史；查找命中可定位根提交；merge 可选择不同父提交；HEAD 跳转能选中并滚动到目标；默认 WIP 保持可见。复核发现并修正了重建列表后以旧对象定位而导致滚动失败的问题。窄屏逐文件 diff 隐藏重复文件头，保留实际 hunk 和内容；选中文件在文件栏保持可见。主代理未在真实项目执行暂存、提交、分支切换或 Worktree 创建。

实现代理最终运行 build/check/test，22 项测试通过。主代理核对了版本 0.2.0、manifest 的 Read/Write 声明、未暂存的项目状态及报告未写入临时访问令牌；没有把代理测试结果称为主代理重新执行。
