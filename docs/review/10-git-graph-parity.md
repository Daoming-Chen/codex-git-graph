# VS Code Git Graph 功能对齐

本轮以 mhutchie.git-graph 为参照，保留现有提交图和多 Worktree 界面。GitLens 的 AI、Agent、Minimap 和云协作功能不在本轮范围内。

## 差距与分工

| 工作流 | 原有能力 | 本轮实施范围 |
| --- | --- | --- |
| 远程同步 | 读取本地远程引用 | Fetch、Pull、Push、Prune；显示操作目标 |
| 引用管理 | 创建和切换本地分支、显示标签 | 分支重命名／删除、标签创建／删除／推送、Remote 配置、检出提交和远程分支 |
| 历史操作 | 普通提交 | Merge、Rebase、Cherry-pick、Revert、Reset、Drop |
| 工作区整理 | 文件暂存／取消暂存 | Stash 管理、指定文件丢弃／清理、冲突标记解决、继续／中止 |
| 历史范围 | 全部历史或一个引用，最多加载 2000 条 | 多引用、通配符、第一父提交、reflog、分页 |
| 比较和文件查看 | 两个提交的统一 diff | 历史提交与工作目录比较、文件内容查看、复制路径 |
| 审阅 | 逐文件查看 | 按提交／比较范围保存已审阅文件 |
| 元数据与协作入口 | 作者、日期、SHA | 提交包含关系、签名状态、附注标签、Issue 链接、PR 表单链接 |

## 实施约定

- 三个子代理分别负责远程引用写操作、历史工作区写操作、只读查询；主代理负责 UI、传输接口与集成验证。
- 写操作沿用 prepare/execute，绑定审阅状态并在执行前复验。删除、丢弃和历史重写要求在界面明确确认。
- 所有自动化写入验证使用 `.test-output/` 下的独立仓库及本地 bare remote，不修改用户仓库历史，不推送用户仓库。
- Git Graph 的编辑器能力在本面板内提供相应文件查看入口；不声称具有 VS Code 专属编辑器集成。
- 以下记录本轮实现、验证及仍保留的边界。

## 实施结果

表中范围已接入 HTTP、MCP 和现有面板。新增 31 类 Git 动作，连同原有 6 类，共 37 类动作；所有 Git 写操作继续经 prepare/execute。

- 顶部「同步」提供 Fetch／Pull／Push；提交与引用右键菜单提供对应操作。
- 「更多」提供 Remote、Stash、仓库配置及配置导入／导出；「筛选」提供多引用、通配符、第一父提交、reflog 与引用显隐。
- 详情提供签名、包含关系、文件内容和审阅进度；文件右键菜单提供精确文件操作。历史提交可与当前操作工作区比较。
- 筛选与分页取代累计 2000 条硬上限，查找仍限定已加载记录。目录分组、列宽和日期格式可配置。
- 审阅与仓库配置保存在 Git common dir 的插件状态文件，跨随机服务端口及 linked Worktree 恢复；90 天过期审阅自动过滤。

## 验证

- `npm test`：47 项通过，0 失败，约 260 秒。覆盖真实 Git、本地 bare remote、状态变化拒绝、远程删除 lease、历史重放、四类冲突继续／中止、Stash 列表漂移、文件操作、HTTP／MCP 及打包 stdio。
- 压力 fixture：2001 条提交、20 个 Worktree、1000 个未跟踪文件；本次 300 条快照约 611 ms、2000 条约 637 ms、1000 文件详情约 985 ms。这是本机一次测试数据，不是性能保证。
- 浏览器实测：同步菜单、提交详情、文件内容、刷新后审阅记录恢复、创建附注标签的检查／执行及标签详情、历史与工作目录比较。
- `npm run build`、`npm run check` 及插件技能校验通过。部分 Git 辅助进程与回环测试受 Windows 受限执行环境影响，在获准的正常环境复验通过。
- 偏好存储的文件符号链接拒绝逻辑已实现；当前环境不允许创建文件符号链接，该测试分支未执行，其余容量与普通文件边界断言通过。

## 剩余边界

- Drop 支持当前分支的单父线性历史；根提交、目标合并提交及跨合并链会明确拒绝。没有交互式 Rebase 编辑器。
- 冲突编辑仍在外部编辑器完成，面板提供刷新、标记解决、继续及中止。
- 不提供普通强制推送、Worktree 删除或多仓库自动发现；HTTP 面板仍绑定单仓库。
- 文件内容在面板内查看，尚无 VS Code 原生编辑器、多文件 diff 编辑器或行内编辑；diff 和内容预览保持 256 KiB 上限。
- Issue／PR／MR 入口使用配置的 URL 模板，尚无内置托管平台识别或 PR／CI 状态集成。
- 尚未覆盖普通 Git Graph 的全部个性化设置，例如自定义快捷键、Gitmoji／Markdown 渲染、头像、mailmap 和提交排序选择。当前对齐的是前述主要工作流，不是所有选项的逐项等价。
