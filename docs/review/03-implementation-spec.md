## 视觉规格

沿用现有主题变量：深色背景 #141619、面板 #1b1e22、边框 #30353c、正文 #e6e9ed、次要文字 #a8b0bd（提高原次要色亮度）、强调 #7ec9ab。浅色背景 #ffffff、面板 #f5f6f8、正文 #20252b、次要 #59636f、边框 #d5dbe2、强调 #17734f。最终需测对比度；不能仅因用了这些数值就宣称通过。常规字 12px，输入和按钮 12px，详情正文 13px，代码 12px/19px；正文不可低于 12px。系统字体；SHA 和 patch 使用等宽字体。

首行 40px，第二行 36px，表头 28px，历史行 28px，底状态栏 24px。常规图线 1.5px、节点半径 3.5px，合并节点双环，WIP 空心虚线环。lane 间距 16px，左右余量各 12px。颜色辅助识别，文字、环形和连接关系同时存在。单一行背景，不做独立卡片；选中整行低饱和绿色背景和 2px 内侧边线。圆角仅控件 4px，内边距 4–8px。

| 宽度 | 导航 | 历史列 | 详情默认位置 |
| --- | --- | --- | --- |
| 420px | 默认收起，菜单式导航抽屉，宽 min(280px, 视口−32px) | 图线 + 引用/摘要；元数据在详情；长图内部横滚 | 底部 45% 可收起；可点「展开详情」替换内容区，保留返回按钮 |
| 640px | 默认收起 | 图线 + 引用/摘要 + 72px 日期；短 SHA 在详情 | 底部 42%；文件清单最多 112px，diff 独立滚动 |
| 960px | 默认收起，可展开 184px | 根据剩余图区域宽度显示作者/日期/SHA | 底部 42%；文件栏 200px + diff |
| 1280px | 默认展开 184px | 主区约 736px：图线、引用/摘要、作者、日期、SHA | 右侧 360px；文件列表 140px 高，diff 在下方；可切到底部 |

断点：容器 <560px 隐藏元数据列；560–799px 保留日期；800–1099px 可显示作者 96px、日期 72px、SHA 70px，条件是图表剩余空间 >=640px；>=1100px 默认右详情 360px，导航 184px。以图表容器实际宽度判定列，不能仅按 window 宽度。导航与详情可分别关闭；记忆仅存在本页面或按仓库本地存储的布局偏好，不保存差异正文/token。

摘要至少 180px、引用最多占摘要单元格 45%；多引用用「+N」展开完整列表，不把摘要挤没。窄宽度展示一个主引用，其他进入 +N。图形列最小 64px，复杂图可扩宽并在图区域内部横滚；表头与行保持同一列模板。不是隐藏溢出图线。无详情时 720px 高窗口至少可见 20 条 28px 历史行；详情展开时须保留 >=7 条可见历史行（420px 宽仍成立）。弹层不出视口，页面整体无横向滚动；diff 可独立横滚。

## 对象与导航

面板启动绑定 repositoryPath。activeWorktree 初始为调用路径对应的 Worktree；若裸仓库则无活动工作区，写入入口不显示。顶部 Worktree 菜单显示完整路径、分支/短 SHA、修改数、锁定/失效。点击浏览某 Worktree 可打开其详情；只有明确「设为操作工作区」改变 activeWorktree。详情中的文件操作以详情 worktree 为对象，按钮旁和提交表单必须持续显示实际路径，不能被顶部另一个对象误导。

引用点击默认跳到该 tip；tip 未加载时通过锚点读取或明确扩大范围加载，不沉默无响应。引用行另有「只看此历史」动作，将 scope 设为该 ref。定位 HEAD 作用于 activeWorktree；若当前 scope 不含该 HEAD，恢复全仓库并显示一次说明，随后定位。unborn HEAD 按钮改为「定位工作区」。

图谱从 refs 和所有可用 Worktree HEAD 获取历史，SHA 唯一。脏 Worktree 各生成一个稳定 ID（规范路径）的 WIP 行，连到自己的 HEAD；多个 WIP 同父也各有独立虚拟边。WIP 边表示工作区来源，不是已经发生的提交。空仓库 WIP 无父，文案「工作区 · 尚无提交」，无文件时同样可展示该行但不画假父边。干净 Worktree 用 HEAD 上的工作区标记和导航表达。unreachable detached HEAD 必须可读；locked 显示原因且仍可读写合法工作区；prunable 或读取失败显示原因，不当成干净，不开放文件操作。

加载边界/浅克隆缺失父节点：绘制向下的虚线终止边，文本提示「父提交未载入」或「浅克隆边界」，不连到不相关节点。默认 300，按 300 续载，上限可暂保留 2000；达到上限明确说明并可通过引用范围浏览旧分支。不要将全部 2000 条作为全库搜索结果。

## 搜索、过滤、选择与比较

查找框 placeholder「查找已加载的提交、作者、引用或 SHA」。大小写不敏感字面子串，本轮没有正则和自然语言解析。查找高亮命中摘要，非命中保持可读；显示「3/12 · 已加载 300 条」，Enter/Shift+Enter 下一/上一命中，Esc 清空查找但不丢选中行。零结果显示「已加载范围内无匹配」，仍显示历史和加载按钮。查询变化不反复抢焦点或滚到第一行；首次查找与显式命中导航才滚动。

scope 下拉「全部历史 / 当前分支历史 / 指定引用」。过滤在 Git 查询层决定可达提交集合，返回选中 tip 的全部祖先（含合并另一父），重新布局；不只是 CSS 变暗。Worktree 节点仅在其 HEAD 属于该范围时显示，顶部仍显示全部 Worktree 可导航；unborn 仅在全部历史显示。更换范围清除不在范围内的行选择并解释，不保留假选中状态。查找范围文字同步更新。

选择行：单击打开详情，上下键移动行，Enter 打开/聚焦详情。Ctrl/Cmd+F 在面板焦点内进入查找，/ 在非输入区进入查找，Esc 逐层关闭菜单/展开详情/详情，不在填写提交消息时误关。焦点可见；弹层关闭返回原触发控件。右键或「更多」有完全相同的可达操作，不能只支持右键。

两端点比较：提交菜单「设为比较起点」，另一提交「与起点比较」。也可在比较栏选择引用；执行前 resolve 为 immutable SHA，显示「A → B」，表示从 A 树到 B 树的差异（不是三点 merge-base diff），支持交换和退出。默认提交详情为第一父 → 当前，合并提交可选择父编号；根提交为空树 → 当前。比较、父编号与路径都显示在 diff 标题，避免把合并结果误读成整个分支改动。不可用端点给具体错误。

## 文件详情与提交闭环

提交详情返回结构化文件清单，含状态、原路径、新路径；点文件单独加载 diff，不能从截断的整份 patch 反解析文件列表。工作区按「已暂存 / 未暂存 / 未跟踪 / 冲突」分组；同文件有 staged 与 unstaged 时显示两个条目并标明不同对照。首个文件默认选中。切换对象取消旧请求；迟到响应不覆盖新选择。

统一 diff：行号、添加/删除符号、内容文本转义；二进制显示「二进制文件，无法显示文本差异」，子模块显示指针变化；重命名显示旧→新路径。未跟踪普通文本按新增内容预览，上限 256 KiB；不跟随符号链接读取仓库外内容，符号链接只显示链接目标文本。超限显示「仅显示前 256 KiB」，大文件仍可在清单选择，不谎报无差异。非法路径或已被移除文件给可重试状态。第一轮不做 hunk stage，避免让部分暂存看起来已支持。

工作区详情有「文件 / 提交」页签。单个条目右侧「暂存」或「取消暂存」；批量操作仅作用于明确勾选的文件，默认不勾选。提交页展示 index 文件数量与清单、工作区路径、分支、作者身份、消息输入。「提交已暂存的 N 个文件」执行一次普通 commit；N=0 或消息为空禁用并说明。用户仍有未暂存文件时显示「N 个文件不会包含在本次提交」，不自动 stage。提交完成选择新 commit，保留未提交文件，不自动 push。

## 首批写操作契约

以下「确认」是产品内的具体表单/按钮，不要求实现代理暂停找用户批准设计。每次执行均重新验证对象。UI 里的设计操作不意味着本次开发能对真实项目执行写入。

| 操作 | 对象与前置检查 | 产品确认与成功行为 | 失败行为 |
| --- | --- | --- | --- |
| 暂存 | 详情 Worktree 的明确路径集合；状态/文件版本未变；非冲突；路径属于状态列表 | 文件按钮或选中 N 个文件按钮即确认；刷新 index 与 diff | 不自动重试；标明状态已变/权限/锁，刷新让用户重看 |
| 取消暂存 | 同上，须有 index 条目；支持 unborn | 点击即确认；只改 index，保留工作目录内容 | 禁止实现为 discard；错误保留文件选择 |
| 提交 | Worktree、HEAD、分支、index tree 与预览一致；index 非空；无冲突及 merge/rebase/cherry-pick 进行中；有 Git identity；detached 先创建分支 | 表单直接「提交已暂存 N 个文件」；不二次泛化弹窗；显示新 SHA | hook/签名/锁/身份失败显示脱敏 stderr；消息保留；不绕过 hooks/签名，不盲目重试；超时后刷新确认是否已生成提交 |
| 创建分支 | 已解析的起点 SHA、新分支名通过 check-ref-format、不存在 | 表单显示起点、名称；默认仅创建不切换，按钮写明「创建分支」 | 不覆盖同名分支；错误保留输入 |
| 切换分支 | 明确 Worktree + 已存在本地分支；工作区含 untracked 完全干净；无进行中操作；分支未被其他 Worktree 占用；HEAD 未变 | 表单显示路径与旧→新分支，点击「切换分支」；刷新图和操作上下文 | 不自动 stash、force 或丢弃；指向占用路径或脏文件列表 |
| 创建 Worktree | 选中起点 SHA + 必填新分支名 + 绝对目标路径；分支不存在；父目录存在且规范化；目标不存在；不在任何已有 Worktree 内；不在 .git 内；无符号链接逃逸 | 表单显示实际父路径/最终路径、起点和新分支；「创建 Worktree」；成功加入导航，可设为操作工作区 | 不删除已有目录，不 force；失败后检查是否残留分支/目录并逐项报告，不自动递归清理 |

本轮 Worktree 创建仅做「新分支 + 新目录」，不支持重用已有分支或 detached 新建，减少占用歧义。查询所有现存 Worktree 占用后仍由 Git 在执行时兜底。分支名前缀默认 codex/，用户可改合法名称。

写入通用机制：单仓库写队列，执行前读取最新状态；允许外部 Git 同时存在但不声称完全原子。暂存预览需文件内容版本或足够可靠的内容指纹，不能只比较 status 字母。返回 operationId、操作、目标、完成/失败/结果未知、时间、结果 SHA/路径；重复提交同一 operationId 不执行两次。按钮 pending 禁用；操作输出可展开，命令参数可查看，但不得输出 token/凭据。网络超时或失联不能直接显示「没有写入」。

## 接口需求

实现可调整函数名，但必须保留语义并统一 HTTP/MCP：

| 查询/动作 | 输入 | 输出重点 |
| --- | --- | --- |
| snapshot | repository、limit、scope(ref/全部)、activeWorktree | refs、唯一 commits、worktrees、hasMore、scope、snapshotVersion、边界信息 |
| detail/files | commit SHA + parent 或 A/B SHA；或 worktree | 结构化文件列表、比较基准、状态版本、HEAD/index 版本 |
| fileDiff | 上述对象 + file identity + staged/unstaged/untracked | patch/预览、binary、truncated、rename、submodule；每次只读所选文件 |
| resolve/jump | 受限 ref 或 SHA | immutable SHA、是否已载入/需补载；不把 ref 当任意 revision 表达式执行 |
| prepareAction | enum action + typed payload | 确认摘要、当前对象版本、可执行/原因 |
| executeAction | prepare 结果绑定的 actionId + operationId | 重验、执行、结果、刷新信息；不能接收任意 shell/任意 git 子命令 |

GET 保持只读；HTTP 写入仅 POST JSON，沿用 Bearer、严格 Host/Origin、仅 loopback，不开 CORS；限制 body 大小、白名单动作和字段、过期 prepare。MCP 写工具独立 readOnlyHint:false，真实填写 destructive/idempotent/openWorld 注解；不能沿用当前全工具只读描述。更新插件 description/manifest/skill 中只读承诺，capabilities 使用官方支持值（先查 schema，不能猜枚举）。

路径按平台规范化并核实 Git common dir 一致；diff 路径必须是返回清单中的文件，不接受任意绝对路径。Git 参数数组，路径使用 literal pathspec/--，名字先验证；拒绝 NUL、参数注入、路径穿越、无效 SHA。不开外部 diff/textconv。读取未跟踪文件核实真实路径及符号链接；Git 写操作遵循本机 hooks/配置，不向外部工具传入凭据。界面只认服务返回能力，不靠按钮隐藏承担授权。
